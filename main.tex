\begin{frame}{Memory}
    Holds both instructions and data.

    \begin{itemize}
      \item \textbf{Unified:} Both instructions and data are stored in the memory under the same address system
      \item \textbf{Random-access:} Any address can be reached in roughly the same time
      \item \textbf{Volatile:} Turning the power off wipes the contents
    \end{itemize}
\end{frame}

\section{Specialized Hardware}

\begin{frame}{Shape of AI compute}
\begin{itemize}
  \item Modern powerful AI models are mostly based on neural networks, whose compute involves lots of \textit{matrix multiplication}
  \item Matrix multiplication can be decomposed into lots of \textit{independent} weighted sums, each very elementary to compute
\end{itemize}
  AI compute prioritizes \textbf{parallelism} over \textbf{complexity}.

    \begin{center}

\end{frame}

\begin{frame}{Limitation of generic computers}
  CPUs specialize in \textbf{sequential} execution of \textbf{complex instructions}.

\begin{itemize}
  \item Each CPU core can handle complex instructions relatively fast, but there are usually \textit{only a few cores} in a CPU
  \item CPUs are usually paired with memory with \textit{low latency} but also relatively \textit{low bandwidth}
\end{itemize}

  \note{
    Letting CPUs handle AI compute is like letting one mathematics professor handle a thousand elementary school math problems.
  }
\end{frame}

\begin{frame}{Limitation of generic computers}{Latency vs. bandwidth}
\begin{itemize}
    \item \textbf{Latency}: How long a single piece of data takes to arrive once requested
    \item \textbf{Bandwidth}: How much data can be moved per second
\end{itemize}
Unfortunately, these are two opposing properties of a memory system.
\end{frame}

\begin{frame}{Ideal hardware for AI compute}
  Hardware capable of performing elementary computations in parallel.

\begin{itemize}
  \item Have \textit{a lot of cores}, each of which can be simple and only capable of executing elementary instructions
  \item Pair with memory with \textit{high bandwidth} at the expense of relatively \textit{high latency}
\end{itemize}

  \note{
    Letting a thousand elementary school students solve a thousand simple math problems.
  }
\end{frame}

\begin{itemize}
  \item \textbf{DDR (baseline):} commonly paired with CPUs, 50--100 GB/s bandwidth
  \item \textbf{GDDR:} commonly paired with gaming GPUs, $\sim$1.8 TB/s bandwidth
  \item \textbf{HBM:} usually only seen on high-end data center GPUs, >2.0 TB/s bandwidth
\end{itemize}

\begin{block}{Fun fact}
  Technically it is possible to:
\begin{itemize}
  \item Pair CPUs with GDDR for a general computer
  \item Pair GPUs with DDR for rendering graphics or computing AI models
\end{itemize}
\end{block}
\end{frame}


\section{Summary}

\begin{frame}{Coming back to Von Neumann}
  Specialized hardware for AI compute \textbf{plugs into} the Von Neumann architecture rather than replacing it.

\begin{frame}{Coming back to Von Neumann}
\begin{itemize}
  \item Specialized hardware accelerates the matrix multiplication parts of computing an AI model
  \item The rest of the Von Neumann architecture handles the rest of an AI system
\end{itemize}
We still need all Von Neumann components, on top of specialized hardware, to build an ``AI computer''.
